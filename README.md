# Reducing Cognitive Load in Institutional Systems: A Human-Centered Approach to Process Navigation

## Overview
University systems are often complex, unclear, and difficult to navigate, especially for first-generation and non-technical students. This creates confusion, delays, and unnecessary stress when completing essential tasks like registration, financial aid, or transcript requests.

This project explores how structured, step-by-step workflows can improve usability and reduce cognitive load.

## Research Question
How can complex institutional workflows be translated into clear, accessible interfaces that reduce cognitive load and improve usability?

## Problem
Students are expected to navigate systems that assume prior knowledge, use unclear language, and present fragmented steps. This creates barriers to access and slows down important processes.

## Solution
Campus Process Translator is a web-based tool that:
- breaks down processes into clear, step-by-step instructions  
- highlights decision points  
- reduces ambiguity  
- improves accessibility for students  

## Approach
- Identified common student pain points through observation and lived experience  
- Translated complex workflows into structured steps  
- Designed an interface focused on clarity and usability  

## Evaluation
Initial evaluation focused on whether structured workflows improved clarity compared to existing process descriptions. Feedback showed that users found the step-by-step format easier to follow and less overwhelming.

## Key Insights
- Users prefer guided steps over dense instructions  
- Clarity improves confidence in completing tasks  
- Reducing decision fatigue improves usability  

## Limitations
- Small sample size  
- Focused on one institution  
- Prototype only  

## Future Work
- Add AI-assisted guidance  
- Personalize workflows  
- Expand to more processes
